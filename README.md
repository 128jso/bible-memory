# 📖 Bible Memory (`bible-memory`)

A modern **TypeScript** web application designed for scripture memorization using **spaced-repetition algorithms**, active recall practice, and interactive verse recitation quizzes.

---

## ✨ Key Features

- 🧠 **Spaced-Repetition Learning Engine**:
  - Implements memory retention schedules to optimize review intervals for maximum long-term scripture retention.
- ⚡ **Type-Safe TypeScript Architecture**:
  - Clean, type-safe data models for passages, review history, and flashcard queues.
- 🎯 **Active Recall & Recitation Quizzes**:
  - Interactive verse fill-in-the-blanks, first-letter recitation prompts, and flashcards.
- 📊 **Progress Analytics & Memorization Streaks**:
  - Tracks review accuracy, mastered passages, and daily study streaks.

---

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/128jso/bible-memory.git
cd bible-memory
```

### 2. Install Dependencies & Launch
```bash
npm install
npm run dev
```
Open **`http://localhost:3000`** in your browser to start practicing!
